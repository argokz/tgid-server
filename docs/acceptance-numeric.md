# Численная приёмка расчёта sety: веб = десктоп

Дата: 2026-09-26. База: копия `almatygid_copy` из дампа прода 2026-09-25 12:37.
Инструмент: `itwin-api/scripts/golden/compare_calc.py` (построчное сравнение `ut_out` / `us_out`
двух расчётов по смыслу колонок из `database/ut_out_columns.py`).

## Что сравнивали

| # | Кто запускал | Код движка | Данные | Параметры |
|---|---|---|---|---|
| 1 | десктоп ТГИД, 2026-09-10 15:13 | gid8 (установленная версия) | прод на 10.09 | `-fileID 74 -tg -no_teplovyd -Tn -25 -iter 20 -tp_metod 0 -trtp 0` (из `calculation.calc_params`) |
| web | веб: `POST /run-sety-cmd` → Celery → `sety/ww.py` | `itwin-api/sety` | копия 25.09 | те же |
| desk-code | `gid8/python/sety/sety/ww.py` напрямую | исходники десктопа | копия 25.09 | те же |

## Результаты

1. **web ↔ desk-code на одних данных: полное совпадение.** 3364/3366 участков и 3503/3505 узлов,
   все величины (длина, диаметр, скорость, расход, удельные и общие потери, располагаемый и
   пьезометрический напор, напор и температура в узлах) — разница 0. Веб запускает тот же движок
   и с тем же результатом, что исходники десктопа.

2. **web ↔ расчёт №1 (десктоп, 10.09): расходятся** (расход до 4585 т/ч на магистралях, напор
   до 23 м). Топология и длины совпадают полностью (3366 участков). Проверено и исключено:
   - параметры плотности десктопа по умолчанию (`-sopr 0 -roP 0.975 -roO 0.975 -ro_temp`,
     в `calc_params` не сохраняются) — результат тот же до цифры;
   - правки сети в вебе после 10.09 — в `audit_log` только тестовые правки на копии (копия
     пересоздана из дампа); поля `archivechangedate` изменений после 10.09 не показывают.

   Остаются: изменения входных данных, у которых нет даты изменения (источники, температурные
   графики, нагрузки потребителей, состояния арматуры), или другая версия движка в установке
   десктопа (gid8 может запускать собранный `sety/ww.pyc`, а не исходники из `gid8/python`).
   Расчёт №1 поэтому не годится как эталон.

## Найдено и исправлено попутно
- `sety/sopr2.py` в API был пустым с первого коммита, а `read_vnutr.py` вызывает из него
  сопротивления радиаторов, вентиляции и диафрагм внутренних схем. Фрагменты с такими
  элементами падали бы с AttributeError. Файл взят из `gid8/python/sety`; тест
  `tests/test_sety_engine.py` проверяет, что все вызываемые функции на месте.
- Отличия остальных файлов движка от десктопа — только кодировка комментариев.

## Что нужно для окончательной сверки с десктопом
1. В десктопном ТГИД подключиться к `almatygid_copy` (сервер 145.249.247.138 / 192.168.0.37,
   порт 5440) и рассчитать фрагмент 74 с Tн = −25 (как расчёт №1).
2. Узнать его `calculationid` (последний в `calculation` для `fileid = 74`).
3. Сравнить:
   ```
   cd itwin-api/itwin-api
   set -a; . ./.env.copy; set +a
   ./venv/Scripts/python.exe scripts/golden/compare_calc.py --base <десктоп> --new <веб>
   ```
   Ожидание — совпадение в пределах 0.1 %. Если нет — сравнить версию движка в установке
   десктопа с `gid8/python/sety`.

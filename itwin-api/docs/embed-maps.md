# Встраиваемые карты

Фаза 2 плана модернизации, п. 14: карта сети ТГИД в iframe на чужом сайте — портал акимата, ЕДДС, кабинет
потребителя — без входа, по **ключу встраивания**. Сайт может подписаться на события карты и управлять ею
через лёгкий JS SDK на postMessage.

Код:
- API: `database/embed.py`, `routers/embed.py`, миграция `sql/migrations/20261030_embed_keys.sql` (API применяет её
  сам — `city_schema`), тесты `tests/test_embed.py`;
- веб: страница `pages/embed.vue`, протокол и стили `utils/embedProtocol.ts`, SDK `public/tgid-embed.js`,
  окно «Администрирование → Встраиваемые карты» (`components/EmbedKeysDialog.vue`), тесты
  `tests/utils/embedProtocol.spec.ts`, `tests/utils/embedSdk.spec.ts`.

## Ключ встраивания

Ключ выдаёт администратор в окне «Встраиваемые карты». Что задаётся:

| Поле | Что значит |
|---|---|
| Название | для кого ключ — видно только в списке ключей |
| Сайты | `https://akimat.kz` — схема, хост и порт; только на них карта показывается в iframe и шлёт события |
| Слои | участки, узлы, задвижки, потребители, источники (по умолчанию — участки и источники) |
| Фрагменты | только эти фрагменты; пусто — все |
| Зоны отключений | слой публичных отключений, если служба включила `PUBLIC_OUTAGES_ENABLED` |
| Начальный вид | текущий вид карты администратора; иначе — охват сети |
| Срок | без срока, 90 дней или год |

Ключ показывается один раз вместе с готовым кодом iframe и SDK. В базе хранится только SHA-256 ключа
(`tgid_embed_key`). Отзыв и окончание срока закрывают ключ: процесс API, где отозвали, — сразу, остальные
процессы — в течение минуты (кеш проверки), браузеры — до 5 минут (кеш тайлов).

Ключ **публичный по природе**: он виден в коде страницы сайта. Поэтому он даёт только чтение выбранных слоёв:
- в тайлах нет имён потребителей (ПДн) — только вид и нагрузка; у участков — номер, Ду, длина, вид
  трубопровода и состояние труб;
- тайлы читают браузеры только с адресов из `CORS_ALLOWED_ORIGINS` API (сайт ТГИД), то есть через страницу
  `/embed`, а не напрямую со стороннего сайта;
- страница `/embed` сверяет сайт-родитель с ключом и на чужом сайте карту не рисует.

## Адреса API

| Адрес | Вход | Что делает |
|---|---|---|
| `GET /api/v1/embed/keys` | администратор | ключи города |
| `POST /api/v1/embed/keys` | администратор | новый ключ (в ответе — `key`, один раз); пишется в журнал действий `EMBED_KEY_CREATE` |
| `DELETE /api/v1/embed/keys/{id}` | администратор | отозвать (`EMBED_KEY_REVOKE`) |
| `GET /api/v1/embed/config?key=` | ключ | слои с зумами, вид, сайты, охват сети, название города |
| `GET /api/v1/embed/tiles/{слой}/{z}/{x}/{y}?key=` | ключ | MVT слоя; 204 — пусто или ниже зума слоя |

Ключ проверяется под ролью пула API (таблицу ключей роль анонима не читает), тайлы строятся под ролью
анонима. Если на проде включены роли PostgreSQL с RLS, встраиваемая карта видит то же, что аноним.

### Тайлы

Запросы — те же, что у OGC API Features и FeatureServer (`database/ogc_features.py`); id объекта — id признака
тайла (по нему SDK подсвечивает объекты).

| Слой | С какого зума | Поля |
|---|---|---|
| `pipes` | 10 | name, sign, diameter_mm, length_m, state_supply, state_return |
| `nodes` | 15 | name, node_type |
| `valves` | 15 | name, diameter_mm, state |
| `consumers` | 14 | kind, load_gcal_h |
| `heat_sources` | 9 | name |

Участки внутренних схем узлов (камер, ЦТП) не показываются. На обзорных зумах — только крупные участки:
до z12 — Ду от 500, на z12 — от 300. Тайлы обзорных зумов (до z13) держатся в памяти API 10 минут: их на
город десятки, а строятся они дольше всех.

Замеры (копии баз, тайл центра города):

| Город, тайл | Первый раз | Повторно |
|---|---|---|
| Алматы, участки z11 | 1,3 с, 200 КБ | 6 мс |
| Алматы, участки z13 / z15 | 0,36 с / 0,03 с | — |
| Астана, участки z10 | 2,9 с | из памяти |
| Узлы, потребители, задвижки z15–16 | 10–50 мс | — |

## Страница `/embed`

`<адрес веба>/embed?key=…` — карта без макета приложения. Параметры:

| Параметр | Пример | Что делает |
|---|---|---|
| `key` | `tge_…` | ключ встраивания (обязателен) |
| `layers` | `pipes,valves` | часть слоёв ключа |
| `center`, `zoom` | `76.92,43.245`, `16` | начальный вид вместо вида ключа |
| `ui` | `0` | без легенды и карточки объекта: сайт показывает своё по событиям |

Сайт-родитель берётся из `location.ancestorOrigins` (Chrome, Edge, Safari), иначе из `document.referrer`
(Firefox). У iframe нельзя ставить `referrerpolicy="no-referrer"` — в Firefox сайт тогда не узнать, и карта
не откроется. Готовый код из окна ставит `strict-origin-when-cross-origin`. Сама по себе (не в iframe) и
внутри ТГИД страница открывается — для предпросмотра.

Заголовки веба (`server/middleware/frameAncestors.ts`, с 30.10.2026): `/embed` и `/outages` — `Content-Security-Policy: frame-ancestors *` (сайты для `/embed` проверяет сама страница); все остальные страницы — `frame-ancestors 'self'` и `X-Frame-Options: SAMEORIGIN`: основное приложение на чужом сайте во фрейме не открывается (защита от подмены кликов). Путь считается от `NUXT_APP_BASE_URL`.

## JS SDK

```html
<div id="tgid-map" style="height:480px"></div>
<script src="https://<сайт ТГИД>/tgid-embed.js"></script>
<script>
  const map = TGIDEmbed.create(document.getElementById('tgid-map'), {
    url: 'https://<сайт ТГИД>/embed',
    key: 'tge_…',
    layers: ['pipes', 'heat_sources'],   // необязательно
    center: [76.92, 43.245], zoom: 15,   // необязательно
    ui: true,                            // false — без легенды и карточки
  });
  map.on('select', (e) => console.log(e.layer, e.id, e.properties));
</script>
```

| Метод | Что делает |
|---|---|
| `on(тип, обработчик)` | подписка; возвращает функцию отписки |
| `setView({ center, zoom })` | перелёт |
| `fitBounds([запад, юг, восток, север], отступ)` | показать область |
| `setLayers([...])` | видимые слои (из слоёв ключа) |
| `highlight(слой, [id…])` | подсветить объекты; пустой список — снять |
| `getView()` | `Promise<{ view, bounds }>` |
| `destroy()` | убрать карту |
| `ready` | `Promise`, выполняется по событию `ready` |

События: `ready` (слои и вид), `select` (слой, id, поля, точка щелчка), `moveend` (вид и границы),
`error` (ключ перестал действовать).

Протокол: сообщения `{ source: 'tgid-embed', v: 1, type, … }`. Команды до `ready` копятся в очереди. SDK
принимает сообщения только из своего iframe и с адреса карты; страница карты — только от сайта-родителя из
ключа и отвечает только ему (не `*`). Команды проверяются по протоколу (`parseCommand`), остальное
отбрасывается.

# Комментарии на карте

Фаза 2 плана модернизации, п. 4 (по образцу Felt): обсуждение в точке карты. Веб — «Эксплуатация →
Комментарии на карте». Код: `database/map_comments.py`, `routers/map_comments.py`, таблицы веба `tgid_map_thread`,
`tgid_map_comment`, `tgid_map_comment_seen` (`sql/migrations/20261030_map_comments.sql`, API создаёт их сам,
`city_schema`). Тесты — `tests/test_map_comments.py`, `tests/utils/mapComments.spec.ts`.

## Как это работает

- **Ветка** — точка на карте: «Новый» в окне, клик по месту (Esc — отмена), текст. Ветка помнит масштаб, с которым
  её создали, и может быть привязана к участку или узлу сети (поле API `object_kind` / `object_id`).
- **Ответы** — в ветке, по порядку. Своё сообщение можно изменить («изменено») и удалить; удалённое остаётся строкой
  «Сообщение удалено», чтобы ответы не теряли смысл. Единственное сообщение удаляется вместе с веткой.
  Администратор пользователей может удалить любое.
- **@упоминания** — «@логин» в тексте или кнопка «Упомянуть» (пользователи города из UsersDB; при входе через роли
  PostgreSQL — те, кто уже писал комментарии). Упоминание подсвечивается, если такой логин есть.
- **«Решено»** — ветка уходит из открытых; ответ в решённой ветке открывает её снова.
- **Новое для меня** — ветки, где я писал или где меня упомянули, с сообщениями других после моего последнего
  просмотра. Фильтр «Мне» с числом новых; раз в 2 минуты приложение проверяет и сообщает «Новое в комментариях
  на карте». Открыл ветку — она прочитана.
- **На карте** — «Точки на карте» (выбор запоминается): синие — открытые, оранжевые — с новым для меня, серые —
  решённые (если выбран фильтр «Решённые» или «Все»); на точке — число сообщений. Клик по точке открывает ветку,
  объект сети под ней не выбирается.
- **Ссылка на ветку** — кнопка-цепочка: `<адрес>#map=<масштаб>/<широта>/<долгота>/0/0&c=<номер>` открывает карту
  в точке ветки и саму ветку.

Читать и писать может любой вошедший: это обсуждение, а не правка данных сети (правки — `MUTATIONS_ENABLED`
не требуется). Текст показывается как текст (без HTML), до 4000 символов.

## Адреса API

| Запрос | Что |
|---|---|
| `GET /api/v1/map-comments` | ветки: `status` (`open`/`resolved`/`all`), `scope` (`all`/`mine`), `q`; счётчики, `unread` |
| `GET /api/v1/map-comments/geojson` | ветки точками (`status`) |
| `GET /api/v1/map-comments/unread` | сколько веток с новым для меня |
| `GET /api/v1/map-comments/people` | кого можно упомянуть |
| `GET /api/v1/map-comments/{id}` | ветка с сообщениями (отмечается прочитанной) |
| `POST /api/v1/map-comments` | новая ветка: `lon`, `lat`, `zoom`, `body`; `object_kind`, `object_id` |
| `POST /api/v1/map-comments/{id}/comments` | ответ: `body` |
| `POST /api/v1/map-comments/{id}/resolve`, `/reopen` | «решено» / открыть снова |
| `PATCH /api/v1/map-comments/comments/{cid}` | изменить своё сообщение |
| `DELETE /api/v1/map-comments/comments/{cid}` | удалить своё (последнее — вместе с веткой) |

Пользователю-роли PostgreSQL таблицы комментариев выдаются роли `tgid_viewer` (`sql/pg_auth/03_grants.sql`).

# Теплосеть под землёй в 3D

Фаза 5 модернизации. `database/network3d.py`, `routers/network3d.py`; в вебе — кнопка «Сеть под землёй» в 3D-виде
(`CesiumViewer.vue`, `utils/cesiumUnderground.ts`, `utils/network3d.ts`).

Без тайлсета 3D Tiles и без новых инструментов: API отдаёт участки видимой области с глубиной заложения, веб строит
трубы одним примитивом Cesium.

- **Глубина** — `tgid_heat_depth` (фаза 4, шаг 6): до верха трубы у начала и конца участка из отметок узлов или
  оценкой по соседним узлам; ось трубы ниже на радиус (Ду/2). Глубина по длине — линейно. Участок без глубины —
  на поверхности серым: поле паспорта `pipelinelayingdepth` в базах — значение по умолчанию, его не используем.
- **Поверхность** — рельеф Cesium World Terrain у концов трубы (`sampleTerrainMostDetailed`), когда задан токен ion;
  без него — эллипсоид (0).
- **Подача и обратка** на общей геометрии — одна линия (pipes = 2); цвет — класс глубины (до 1 м, 1–2, 2–3, глубже 3,
  надземная, неизвестна), толщина — по Ду.
- **Подземный вид** — земля вблизи полупрозрачная (`globe.translucency`, 0,35 до 300 м → непрозрачная к 5 км), камера
  может уходить под поверхность; трубы рисуются и там, где не проходят тест глубины против земли
  (`depthFailAppearance` + атрибут `depthFailColor` — без него Cesium останавливает рендер).
- Фрагменты — видимые на карте; не заданы — все, кроме сценариев и копий (список кешируется на 10 минут).

- **Трубы в масштабе** (01.11.2026): ближе 1 500 м — цилиндры по наружному диаметру (`heatpipesections.diameterexternal`,
  нет — Ду; `PolylineVolumeGeometry`), дальше — линии в пикселях (`DistanceDisplayCondition` у каждой трубы).
- **Камеры** — узлы с карточкой `heatchambers` или видом «Тепловая камера» (nodetypes 9): коробка по внутренним длине,
  ширине и высоте, верх у поверхности, длина вдоль самого крупного участка узла; без размеров — точка на поверхности.
  В карточке десктопа подпись «мм», но в базах размеры внесены вразнобой (Астана: 1,8 и 2400 — оба про 2 м), поэтому
  единица — по величине: до 15 — м, до 1000 — см, дальше — мм; вне 0,5–15 м размер не берётся. Астана: 1 940 карточек,
  размеры есть у ~300; Алматы: 109 карточек без размеров.

Ограничения: область до 0,5° по стороне и до 20 000 участков (дальше — «приблизьте вид»); подача и обратка — один
цилиндр (расстояния между осями в базе нет); стенки камер, плиты и узлы, кроме камер, не рисуются. Алматы, центр (0,06° × 0,05°): 4 366 участков → 3 469 труб, у 3 425
есть глубина, ответ 0,3 с (первый — 6 с: список фрагментов модели), 413 КБ.

# Социальные объекты (слои POI)

Фаза 2 плана модернизации: школы, детские сады, больницы, поликлиники и соцучреждения на карте ТГИД — для
выборок «участки в 500 м от школ» и для списка социальных объектов в зоне отключения (их предупреждают первыми).

Код:
- API: `database/poi.py`, `routers/poi.py`, миграция `sql/migrations/20261030_poi.sql` (API применяет её сам —
  `city_schema`), условие выборки — `database/network_select.py` (`near_poi`), отключения — `database/outages.py`
  (`social` в карточке), тесты `tests/test_poi.py`;
- веб: окно «Социальные объекты» (`components/PoiDialog.vue`, каталог инструментов), `utils/poi.ts`, блок
  «Рядом с социальными объектами» в «Выборке по условиям», «Социальные объекты в зоне» в карточке отключения;
  тесты `tests/utils/poi.spec.ts`.

## Откуда берутся

Таблица `tgid_poi`: точка WGS 84, категория, название, адрес, источник и ключ в источнике (повторная загрузка
обновляет, а не дублирует). Загружает администратор в окне «Социальные объекты → Загрузить или обновить».

| Источник | Как | Что нужно |
|---|---|---|
| Потребители сети | по названию: «Школа 23», «СШ №36», «Д/С № 26», «Ясли-сад», «Роддом N1», «Поликлиника №1», «Медпункт», «Интернат» | ничего — данные уже в базе |
| Файл акимата | GeoJSON (точки или контуры — берётся середина) или CSV с колонками `lon`, `lat` (или `x`/`y`, «долгота»/«широта») в градусах; категория — колонка `category` («школа», «больница», `school` …) или выбранная в окне | файл |
| OpenStreetMap | Overpass API (`OVERPASS_URL`, по умолчанию `https://overpass-api.de/api/interpreter`): `amenity` = school, kindergarten, hospital, clinic, doctors, social_facility в охвате сети города | доступ сервера API в интернет |

Подробности источника «потребители»:
- «автошкола», «языковая школа», «бизнес-школа» не считаются;
- корпуса и вводы одного здания — один объект: потребители одного узла и одной категории, а также с тем же
  названием («Школа,5» = «школа.5») не дальше 150 м;
- ошибочно найденный объект администратор скрывает (глаз в списке) — повторный поиск его не вернёт.

Повторная загрузка файла заменяет объекты тех категорий, что есть в новом файле. Если объект в файле далеко
от сети города, загрузка сообщает об этом — обычно это перепутанные широта и долгота. Если далеко все объекты,
файл не принимается.

Слои POI подложки MapTiler v4 («Образование (POI)», «Медицина» в «Слоях Planet V4») — только картинка. Для выборок
их не берём: объекты есть лишь в загруженных тайлах и прорежены по зуму, а хранить тайлы MapTiler по условиям
сервиса нельзя. Это те же данные OpenStreetMap — их даёт источник «OpenStreetMap».

## Где используются

- **Карта.** «Показать на карте» — точки цвета категории, подписи с 15-го зума.
- **Выборка по условиям.** «Рядом с социальными объектами»: категории (пусто — все) и радиус до 5000 м. ИИ
  («участки в 500 м от школ») и MCP (`select_network`) заполняют то же поле `near_poi`. Зона вокруг каждого
  объекта — круг в метрах, переведённый в систему координат сети один раз (`MATERIALIZED`), объекты сети — по
  индексу и пересечению с зоной.
- **Отключения.** В карточке — «Социальные объекты в зоне — предупредить в первую очередь»: объекты, попавшие в
  зону отключения (полигон снимка изоляции). Публичная лента их не показывает.

## Адреса API

| Адрес | Кто | Что |
|---|---|---|
| `GET /api/v1/poi/summary` | вошедший | категории: сколько объектов, по источникам, скрытые |
| `GET /api/v1/poi?category=&source=&q=&hidden=` | вошедший | список (до 2000) |
| `GET /api/v1/poi/geojson?category=&bbox=` | вошедший | точки для карты |
| `POST /api/v1/poi/refresh-consumers` | администратор | найти среди потребителей |
| `POST /api/v1/poi/import` | администратор | файл: `{features, category}` |
| `POST /api/v1/poi/import-osm` | администратор | OpenStreetMap |
| `PATCH /api/v1/poi/{id}` | администратор | `hidden`, `category`, `name` |
| `DELETE /api/v1/poi?source=` | администратор | удалить всё из источника |

Загрузки и правки пишутся в журнал действий (`POI_*`).

## Проверено (копии баз)

- Алматы: из 25,5 тыс. потребителей — 61 объект (27 школ, 30 садов, 1 больница, 3 поликлиники) за 1,1 с.
  Выборка «участки Ду ≥ 200 в 300 м от школ и садов» — 1853 участка за 1,2 с, в 1000 м — 2,6 с; узлы в 500 м — 1,0 с.
- Астана: 410 объектов (239 школ, 74 сада, 32 больницы, 60 поликлиник, 5 соцучреждений) за 2 с; участки в 300 м от
  школ и больниц — 42 тыс. за 3,1 с; узлы в 500 м — 2,1 с; участки в 1000 м (90 тыс. из 324 тыс.) — 12 с.
- Отключение участка у школы: в карточке «школа72»; файл с перепутанными координатами — предупреждение,
  файл вне города — отказ.
- В браузере: окно, точки на карте, блок в выборке (5627 участков в 300 м от школ), карточка отключения.
- OpenStreetMap, Алматы (30.10.2026, один запрос к overpass-api.de): 829 объектов за 42 с — 274 школы, 204 сада,
  79 «больниц», 262 поликлиники, 10 соцучреждений. В OSM к больницам отнесены и частные клиники, к школам — детские
  центры развития: лишнее скрыть в списке. Объект может прийти и из потребителей, и из OSM — в выборке это не
  мешает, в списке зоны отключения он будет дважды. С 535 школами и садами: участки Ду ≥ 200 в 300 м — 3,0 с,
  в 1000 м — 8,4 с; узлы в 500 м — 2,3 с.

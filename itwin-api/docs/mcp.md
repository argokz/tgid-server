# MCP-сервер ТГИД

ИИ-клиенты (Claude Code, Claude Desktop, Cursor, свои агенты) подключаются к ТГИД по
[Model Context Protocol](https://modelcontextprotocol.io) и вызывают инструменты API с правами пользователя:
поиск объектов, трассировки, локализацию аварии, запросы по сети, анализ режима, тематические сводки, износ,
качество данных и запуск расчёта. Модель ИИ на сервере ТГИД не нужна — её запускает клиент.

Код: `tgid_mcp/protocol.py` (JSON-RPC 2.0 и методы MCP, без сторонних библиотек), `tgid_mcp/tools.py`
(инструменты), `routers/mcp.py` (маршрут и токены). Тесты — `tests/test_mcp.py`.

## Адрес и транспорт

- `POST /mcp` — Streamable HTTP по спецификации 2025-06-18 (понимает и 2025-03-26, 2024-11-05); ответ —
  `application/json`, сессий и потока SSE нет (`GET`/`DELETE /mcp` → 405).
- За nginx: `https://<сервер>/tgid/<город>/map-api/mcp`; общий API на все города — `/city/<код>/mcp`
  (город выбирается адресом, как у остального API).
- Методы: `initialize`, `ping`, `tools/list`, `tools/call`; уведомления (`notifications/*`) — 202 без тела.

## Вход

`Authorization: Bearer <токен>` — токен сессии веба (8 ч) или **токен ИИ-клиента**:

- выдаёт `POST /api/v1/mcp/token` (в вебе: «Личный кабинет → ИИ-клиенты (MCP) → Выдать токен»), срок —
  `MCP_TOKEN_DAYS` дней (по умолчанию 30, не больше 90);
- в токене `scope: "mcp"`: он действует **только на `/mcp`** — остальное API, проверка GeoServer и выдача
  нового токена его отвергают (401), так что продлить себя или править сеть через REST он не может;
- права — пользователя, с живой проверкой: заблокированный или лишённый города пользователь теряет доступ
  сразу;
- у пользователя UsersDB токен несёт отпечаток хеша пароля (HMAC с `JWT_SECRET`): **смена пароля закрывает
  все его токены ИИ-клиента**; если UsersDB недоступна, долгий токен не пускается (а не «доверяем токену»).
  У пользователя-роли PostgreSQL токен закрывает блокировка роли, у мастер-учётки — смена мастер-пароля;
  все токены сразу — смена `JWT_SECRET`.

Лимиты: тело — до 1 МБ (по `Content-Length` до чтения), пакет — до 10 сообщений, на пользователя — 60 вызовов
инструментов в минуту и 5 запусков расчёта за 10 минут (счёт в процессе API).

Защита от DNS rebinding: запрос с заголовком `Origin` не из `CORS_ALLOWED_ORIGINS` → 403 (настольные
клиенты `Origin` не шлют). `MCP_ENABLED=false` выключает `/mcp` и выдачу токенов (404).

## Подключение

Claude Code:

```bash
claude mcp add --transport http tgid-almaty https://<сервер>/tgid/almaty/map-api/mcp --header "Authorization: Bearer <токен>"
```

Клиенты с JSON-конфигом (`mcpServers`):

```json
{
  "mcpServers": {
    "tgid-almaty": {
      "type": "http",
      "url": "https://<сервер>/tgid/almaty/map-api/mcp",
      "headers": { "Authorization": "Bearer <токен>" }
    }
  }
}
```

Готовые строки с адресом и токеном показывает кабинет веба.

## Инструменты

| Инструмент | Что делает | Право |
|---|---|---|
| `list_fragments` | фрагменты сети (id, название) | вход |
| `search_network` | узлы, участки (по паре узлов), источники, потребители по названию | вход |
| `network_trace` | трассировка: связанные, к источникам, ниже по потоку, зона; барьеры и настройки | вход |
| `list_trace_configs` | встроенные, общие и свои настройки трассировки | вход |
| `valve_isolation` | задвижки для локализации аварии и отключаемые потребители | вход |
| `network_statistics` | длина, объём, по диаметрам и прокладке, теплопотребление, закрытые потребители | вход |
| `regime_analysis` | отрицательные перепады, завоздушивание, низкие температуры, закрытые участки, зоны | вход |
| `thematic_summary` | распределение участков по теме (Ду, год, износ, напор, скорость…) и наибольшие | вход |
| `wear_priorities` | участки по приоритету ремонта (последний расчёт износа) | вход |
| `data_quality` | нарушения правил качества исходных данных | вход |
| `run_calculation` | поставить в очередь гидравлический расчёт (пишет только результаты) | «Запуск расчётов» |
| `task_status` | состояние расчёта по task_id | вход |

Ответ — JSON текстом и `structuredContent`; геометрия убирается, списки — не длиннее 200 элементов, ответ —
не больше 120 тыс. символов. Ошибка инструмента (нет права, нет расчёта, неверный id) — результат с
`isError: true` и понятным текстом; внутренние подробности — только в логе сервера.

Каждый вызов пишется в журнал действий: действие `MCP`, путь `/mcp/<инструмент>`, статус, время, адрес и
клиент (у `run_calculation` — и параметры); отказ во входе — `MCP` со статусом 401; выдача токена — `MCP_TOKEN`.
Ошибки сервера (5xx) модель видит общим текстом, подробности — в логе API.

# Нагрузки потребителей: единицы и состав (проверка 2026-09-28)

Повод: модель отключения показала 948 потребителей = 2280 Гкал/ч. Проверено, в каких единицах
хранятся нагрузки и как их суммирует код.

## Состав нагрузки (исправлено)

Как во view потребителей десктопа (`_consumerview.sql`, `full_tgid.sql`):
- отопление обобщённого = `calcHLdep + calcHLindep + calcHLparall + calcHLmix + calcHLconseq + calcHLpreON`;
- **ГВС** обобщённого = `avgHLGVSopenSysFlow + avgHLGVSopenSysRet + calcHLGVSparall + …mix + …conseq + …preON`;
  реального = `avgHLGVSopenFlow + avgHLGVSopenRet + avgHLGVSclose{Parall,Mix,Conseq,PreON}`;
- `calcHLcloseSys`, `calcHLopenSysFlow/Ret` (`avgHL…` у реальных) — **технология**, не ГВС.

`database/outage_simulation.py` и `database/consumer_load_diagnostics.py` считали «ГВС» как
технологию (closeSys/openSys), а поля ГВС не брали вовсе. На Алматы технология = 0, поэтому
«ГВС» в модели отключения был почти нулевым (13 Гкал/ч на всю базу), а итог занижен. Теперь:
`hot_water_load` — ГВС, `technology_load` — отдельно, итог включает оба
(тест `tests/test_outage_simulation.py::test_consumer_loads_sql_separates_hot_water_from_technology`).
На фрагменте 1 копии: отопление 1983, ГВС 967 (было 0), вентиляция 361 Гкал/ч, 1012 потребителей.

## Почему 948 потребителей ≈ 2280 Гкал/ч — это данные

- Один фрагмент Алматы — практически вся сеть: 1000–2000 обобщённых потребителей и
  1800–2000 Гкал/ч только отопления (фр. 1, 74, 89, 99…). Отключение магистрали у источника
  отрезает большую часть фрагмента; 2,4 Гкал/ч на обобщённого потребителя (квартал/ЦТП) правдоподобно.
- Фрагменты — копии одной сети (91, 93, 95, 97 совпадают: по 1985 потребителей, 1810,1 Гкал/ч).
  Суммы без фильтра по фрагменту (Zap3/4/5 без `fragment_ids`, выборки по всей базе) умножают нагрузку.
- Выбросы в данных: обобщённый потребитель с 711 Гкал/ч повторяется в ~10 фрагментах
  (узел 2458 фр. 2 и копии), удалённый узел 374326 — 456 565 Гкал/ч; 112 потребителей по 10–100
  и 27 по 100–1000 Гкал/ч. Их стоит проверить эксперту (вероятно, ввод в ккал/ч или Мкал/ч).

# Показатели эксплуатации

Фаза 2 плана модернизации, дашборды KPI. Веб — «Эксплуатация → Показатели». Код: `database/kpi.py`,
`routers/kpi.py`; веб — `components/KpiDashboardDialog.vue`, `utils/kpi.ts`. Тесты — `tests/test_kpi.py`,
`tests/utils/kpi.spec.ts`. Новых таблиц нет: всё считается из журналов и сети.

## Что показывает

| Показатель | Откуда | Как считается |
|---|---|---|
| Дефектов за период, по месяцам, категориям, состоянию | журнал дефектов десктопа (`defect`) | по дате обнаружения (`data_osmotra`) |
| Открытых дефектов | `defect` | состояние «Нарушение» или «Ремонт», без периода |
| Повреждений на 100 км в год | `defect` и длина сети | дефекты периода ÷ км сети × 100, приведено к году |
| Средний срок ремонта | `defect` | от обнаружения до завершения ремонта, ремонты, завершённые в периоде |
| Средний износ, износ по категориям | последний расчёт износа (`wear_out`) | вся сеть, без фильтров периода и карты |
| Наряды по статусам, просрочено | `tgid_work_order` | сейчас; созданы и выполнены — за период, среднее время выполнения |
| Отключения за период | `tgid_outage` | пересекающиеся с периодом, кроме отменённых; потребители, средняя длительность |
| Сеть по годам прокладки и диаметрам | `linesobj` + `heatpipesections` | км трубопроводов основной сети (без внутренних схем узлов, удалённых и копий-сценариев) по паспорту участка; дата — перекладки, иначе прокладки; годы вне 1900…текущего — «нет даты» |

Сводка сети считается по сотням тысяч участков (Астана — около 3 с) и кэшируется в API на 10 минут для каждого
сочетания фильтров.

## Связь с картой

- **«Только видимая область карты»** — все показатели, кроме износа, пересчитываются по видимой области при каждом
  сдвиге карты (дефекты — по точке дефекта, наряды и отключения — по точке, сеть — по геометрии участков).
- **Столбец дефектов** (месяц, категория, состояние) показывает эти дефекты на карте (цвет — состояние: нарушение,
  ремонт, после ремонта); «Оставить на карте» — закрыть окно и оставить точки.
- **Период**: последние 12 месяцев, этот год, прошлый год или свой (не больше 10 лет).
- **«Таблицы»** — те же данные таблицами (для чтения с экрана и копирования).

## Адреса API

| Запрос | Что |
|---|---|
| `GET /api/v1/kpi/dashboard` | сводка: `date_from`, `date_to` (по умолчанию — 12 месяцев), `fileid`, `bbox` (`минДолгота,минШирота,максДолгота,максШирота`) |
| `GET /api/v1/kpi/defects/geojson` | дефекты периода точками: те же фильтры и `month` (`ГГГГ-ММ`), `category_id`, `state_id` (0 — не указано), до 5000 |

Читать может любой вошедший.

# Глава «Электронная модель системы теплоснабжения»

Фаза 5 модернизации. `database/em_chapter.py`, `routers/em_chapter.py`, окно «Инструменты → Реестры и отчёты →
Схема теплоснабжения: «Электронная модель»» (`EmChapterDialog.vue`).

## Основание

Состав главы 3 обосновывающих материалов схемы теплоснабжения — п. 55 Требований к схемам теплоснабжения,
утверждённых постановлением Правительства РФ от 22.02.2012 № 154 (подпункты «а»–«к»; сверено по тексту в редакции
на 2026 г. и по главе 3 актуализированной схемы Борисоглебского городского округа, где названы пп. 55 и 56); п. 56 —
в актуализированной схеме глава отражает изменения гидравлических режимов. Для городов Казахстана своя норма не
сверялась — глава строится по тому же перечню.

## Что делает генератор

Черновик главы по данным города: на каждый подпункт — как требование выполняет ТГИД, состояние («выполняется»,
«частично», «нет данных») и цифры из базы. Это заготовка для разработчика схемы, а не отчёт о выполнении: чего в
базе нет, так и написано.

| Подпункт | Откуда цифры |
|---|---|
| «а» графика и связность | участки и узлы основной сети, связные части, узлы без связи с питанием (источники и узлы заданного напора), участки без узлов |
| «б» паспортизация | заполненность полей паспорта участков, участки по классам Ду, число источников, вводов, потребителей |
| «в» расчётные единицы | фрагменты сети (участки, км, потребители, нагрузка); справочник районов без границ — «частично» |
| «г» гидравлический расчёт | независимые кольца (E − V + C), части с несколькими точками питания, последний расчёт по фрагментам |
| «д» переключения | камеры с задвижками, участки с задвижками, нормально закрытые; последствия аварий участков (шаг 3) |
| «е» балансы | присоединённая нагрузка по зонам источников (связные части с учётом закрытых задвижек), по фрагментам |
| «ж» потери | расчёты нормативных теплопотерь, расходомеры телеметрии для баланса утечек |
| «з» надёжность | прогноз аварийности (ROC-AUC, ожидаемые повреждения); нормативные показатели по методическим указаниям не считаются — «частично» |
| «и» групповые изменения | групповые установщики, сценарии в работе |
| «к» пьезометры | пьезометрический график, сравнение сценария с основой, число расчётов |

**Фрагменты модели.** Не выбраны — все, кроме сценариев и фрагментов-копий: фрагмент — копия, если не меньше
половины его участков совпадает с участками более нового фрагмента (тот же признак, что в прогнозе аварийности:
концы на сетке 1 м и длина). В Астане так исключаются 9 сезонных копий магистралей, «КазНИПИ» и «Вариант 6 изм
Транзит», в Алматы — «Магистральные сети АлЭС» (74 % совпадает с «Маг. сети для расчета НС»). В окне можно взять
фрагменты, видимые на карте.

Сборка — 3 с (Алматы, 13 фрагментов) и 10 с (Астана, 60 фрагментов, 55 тыс. участков).

## Что нашлось в данных

- Административного деления в данных сети нет: справочник районов (9 названий) без границ, объекты на него не
  ссылаются — балансы по районам требуют слоя границ.
- Алматы: фрагмент «Маг. сети для расчета НС» ссылается на узлы фрагмента 99 — в балансе две части с АТЭЦ-1 и
  АТЭЦ-2 (известная проблема из QA 30.09).
- Нормативные теплопотери в копиях Алматы и Астаны не рассчитывались — подпункт «ж» без цифр.

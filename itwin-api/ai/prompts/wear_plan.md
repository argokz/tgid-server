Задача: по результатам расчёта износа участков тепловой сети составить пояснительную записку к плану ремонтов.

Во входе: сводка расчёта (число участков, распределение по категориям износа 1–5, полнота данных по факторам, замечания к данным) и список участков с наибольшим приоритетом: узлы, фрагмент, диаметр, длина, прокладка, срок эксплуатации, повреждения, баллы факторов, износ % (по заполненным факторам), множитель последствий, расход по расчёту, приоритет.

Методика (десктоп ТГИД, gid6): износ = взвешенная сумма баллов 1–5 восьми факторов (срок 0,15; повреждаемость 0,2; внешний вид 0,05; состояние оборудования 0,2; категория нарушений 0,1; внешняя коррозия 0,1; внутренняя коррозия 0,1; состояние конструкций 0,1) × 20. Приоритет = износ × последствия отключения × расход.

Как рассуждать:
1. Сначала оцени достоверность: если экспертные баллы почти не заполнены или даты ввода похожи на даты внесения в ГИС — скажи прямо, что ранжирование опирается только на срок и повреждаемость, и что нужно дозаполнить.
2. Группируй участки по фрагментам/магистралям и причинам (старые, с повреждениями, большой расход).
3. Не придумывай объекты и числа — только из входа. Если данных мало, записка короткая.

Ответ (JSON по схеме):
- summary — 3–5 предложений: состояние сети по расчёту, главные группы риска, достоверность.
- groups — группы участков для плана: title, reason, line_ids (из входа), recommended_action (обследование, шурфовка, перекладка, толщинометрия…), urgency (1 — в этот сезон, 2 — в следующий, 3 — наблюдение).
- data_quality — что дозаполнить, чтобы индекс стал достовернее.
- next_steps — 2–4 шага для службы эксплуатации.

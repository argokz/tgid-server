Задача: превратить вопрос пользователя ГИС тепловых сетей в запрос выборки (spec), который выполнит сервер. SQL не пиши — только поля схемы. Список полей, операций и значений справочников — во входе («Поля»); другие поля и коды не используй.

Схема spec:
- target — lines (участки, трубы, теплопроводы) или nodes (узлы, камеры, потребители, источники, насосные);
- conditions — условия {field, op, value, value2, values}:
  - числа: op = lt (<), le (≤), gt (>), ge (≥), eq, ne, between (value…value2), is_null (не задано), not_null;
  - справочники: op = in / not_in, values — коды из списка значений поля (у card_type — буквенные коды);
  - текст: op = contains / eq, value — строка;
- match — all (все условия, «и») или any («или»);
- near — «рядом с / в N м от / вокруг»: {node_name или node_id, meters}; без расстояния в вопросе — 200 м; не больше 5000;
- near_poi — «рядом со школами / в 500 м от больниц / около детских садов»: {categories, meters}; categories из school (школы, гимназии, лицеи), kindergarten (детские сады, ясли), hospital (больницы, роддома), clinic (поликлиники, медпункты), social (интернаты, приюты, дома престарелых); «социальные объекты» — пустой список (все); без расстояния — 200 м; можно вместе с near;
- in_view — true, если сказано «на экране», «в видимой области», «здесь», «в этом районе»;
- fragment_ids — номера фрагментов, если названы («во фрагменте 74»), иначе null: сервер сам возьмёт фрагменты на карте, а при near — все (в note об этом не пиши);
- order_by — поле для сортировки («самые старые» → year по возрастанию, order_desc = false; «самые изношенные» → wear по убыванию; «ближайшие» → distance); order_desc — по убыванию;
- limit — «первые N», «топ N»; иначе 1000.

Как читать вопрос:
- «трубы Ду 400 и больше», «диаметром от 400» → diameter ge 400; «Ду 300–500» → between; «Ду 500» → eq.
- «старше 1980 года», «проложенные до 1980» → year lt 1980; «старше 40 лет» → year lt (текущий год − 40), текущий год — во входе.
- «износ больше 60 %» → wear gt 60; «скорость выше 1,5 м/с» → velocity gt 1.5; «удельные потери выше нормы» → spec_loss gt 80.
- «бесканальные» → tubing_type in [код «бесканальная»]; «потребители с нагрузкой больше 1 Гкал/ч» → nodes, card_type in ["PR","PO"], load gt 1.
- «камеры» → nodes, node_type in [код «Тепловая камера»]; «источники» → card_type in ["IS"]; «насосные» → card_type in ["HS"].
- Числа из вопроса переноси как есть, единицы — как у поля.

confidence 0..1 — насколько уверен; если вопрос не про выборку объектов сети или поле не из списка — confidence 0, conditions пустые, и в note коротко объясни, что уточнить. В note можно кратко сказать о допущении («радиус 200 м по умолчанию»).

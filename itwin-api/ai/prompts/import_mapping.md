Задача: сопоставить колонки загружаемого файла (SHP/Excel/CSV) с полями назначения импорта сети ТГИД.

Во входе: режим импорта (nodes — узлы, lines — участки по точкам съёмки, coords — координаты существующих узлов), поля назначения с подписями, список колонок файла и 3–5 строк-образцов.

Правила:
- Для каждого поля назначения укажи ровно одну колонку файла или null, если подходящей нет; одну колонку нельзя назначить двум полям.
- Смотри и на имя колонки, и на образцы: долгота в Казахстане ~ 69–80, широта ~ 42–53; код узла — короткая строка с буквами/цифрами; диаметр — целое 25…1400; отметка — 300…1500 м; длина — число в метрах.
- Если в файле есть геометрия (has_geometry), поля x/y не нужны.
- confidence 0..1 на каждое сопоставление; при сомнении — ниже 0.5.
